# GPT-Image-2 图片生成 Skill

## 工作流总览

```
收到需求
  ├→ Phase 0: 判断复杂度（简洁/扩展/定制/编辑/跳过模板）
  ├→ Phase 1: 确认场景类型 + 核心主体 + 用途
  ├→ Phase 2: 按场景问核心参数
  ├→ Phase 3: 确认尺寸/质量/数量
  ├→ Phase 4: 展示 prompt → 用户确认
  ├→ Phase 5: 调用脚本生成 → 反馈循环
```

## Prompt 写作 5 大铁律

1. **主题前置** — 核心主体放开头
2. **结构化场景** — 场景→主体→风格→镜头→光线→构图→约束
3. **文字用英文引号** — `"..."`
4. **明确镜头与光线** — 焦距/光圈/角度/色温
5. **编辑时分离变与不变** — `Change:` / `Preserve:`

## 模板盲评速查

| 场景 | 模板有效？ | 做法 |
|------|-----------|------|
| Pixar 3D / 概念插画 | ❌ 0:3 大败 | **不套模板**，保持简洁叙事 |
| 写实摄影 | ⚠️ 3:3 平手 | 简洁模式即可 |
| App UI / Logo / 编辑 | ✅ 2:0-3:0 大胜 | **必须套模板** |
| 电影质感 | ✅ 2:1 胜 | 推荐套模板 C |
| 产品 Mockup | ⚠️ 1:2 败 | 用户描述已具体时不套 |
| 其他 | ⚠️ 1:1 平手 | 视情况定 |

## 模板参考

所有 30+ 模板（A~K）在 `references/prompt-guide.md`。含写实/产品/电影/Pixar/App UI/信息图/Logo/等轴/创意/编辑/插画全场景。

按以下决策选择模板：
- App UI → 必须用模板 E
- Logo/品牌 → 必须用模板 G（先确认 G1/G2/G3 层级）
- 编辑现有图片 → 必须用模板 J（J1-J10 子模板决策树见参考文件）
- 电影质感 → 推荐模板 C
- 创意概念 → I1-I10 子模板决策树（交易卡/人偶/全景/漫画/拆解板/水墨海报/科普海报/品牌板/动作表/收藏玩具）
- Pixar 3D / 概念插画 → 不套模板，保持简洁

## 调用 API 生图

```bash
export GPT_IMAGE_API_KEY="sk-xxxx"

python .opencode/skills/gpt-image-gen/scripts/gpt_image2_gen.py \
  --prompt "your prompt" \
  --size "1024x1024" \
  --n 1 \
  --quality high
```

参数说明：
- `--prompt / -p`: 已确认的 prompt 文本
- `--size / -s`: 尺寸（默认 1024x1024）
- `--n`: 生成张数（默认 1）
- `--quality / -q`: high 或 medium
- `--output-dir / -o`: 输出目录（默认当前目录）
- `--seed`: 固定随机种子（可选，用于复现）

## 尺寸速查

1:1=1024×1024（Logo/头像）, 4:5=1024×1280（Instagram）, 3:4=1024×1365（交易卡/海报）, 16:9=1536×864（封面/横版）, 9:16=864×1536（手机全屏）, 2:1=1536×768（全景/Banner）, 2.39:1=1536×642（电影宽银幕）

## 质量检查（生成前自检）

- [ ] 主体在 prompt 开头？
- [ ] 分段清晰？
- [ ] 文字用引号包裹？
- [ ] 镜头参数明确？
- [ ] 光线描述具体？
- [ ] 没有 "8K ultra detailed" 堆砌？
- [ ] 没有冲突风格？
- [ ] 没有把简单需求过度工程化？
- [ ] 创意类需求跳过了模板？

## 默认值

色调=warm, 光线=natural soft light, 背景=clean gradient, 构图=centered, 质量=high, 尺寸=1:1
